Tide Beacon: you are the keeper of the last lighthouse on a stormy night sea. Aim the beacon beam with the mouse to burn back the fog wraiths, light the ships so they find the harbour, gather drifting starlight to charge a pulse blast, and survive 10 waves until dawn. Three hearts, a score, a combo, and a win at dawn.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Mouse aims the beam, click or Space fires the pulse blast when charged, P pauses, M mutes, R restarts after the game ends.
